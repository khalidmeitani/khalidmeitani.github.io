# Publication media

Upload each publication's figures and videos to its matching folder.

Recommended file names:

- `figure-1.jpg`, `figure-2.png`, and so on
- `video-1.mp4`, `video-2.mp4`, and so on
- `video-thumbnail.jpg` for a video preview image

Please use short, descriptive file names with lowercase letters and hyphens. After
uploading files, note which publication they belong to and provide any captions,
image descriptions, and abstracts so they can be added to the website.

The `.gitkeep` file inside each folder is only a placeholder and can be left in
place or deleted after other files have been uploaded.
